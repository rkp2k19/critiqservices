# Critiqservices

Create a website for Tenant Search Services. Please consider all these points which given below

•	Use the REPLAD_Logo.jpeg as logo
•	Display 7026400502 as Contact number with Phone and Whatsapp Icon
•	Display the Location as Bangalore with location Pin

The Body will have the below contents
•	Big Search Bar will display on top of the page body
•	Where the Client keying the location of a place.
•	If any property of that location is available to rent then it will filter all of them only
•	If no property then display no property found

Property Listing 
•	List 4 dummy property with few details
•	Display only images and a property ID

Onclick any Property from the list
•	Display the Property Description and images
•	Display only 100character of the Property Description then the link read more
•	On click of read more ask for Mobile Number and Email ID
•	To validate the Mobile Number send OTP to the mobile number. The User has to keying the OTP and validate
•	To validate the EMAIL ID send OTP to the email id. The User has to keying the OTP and validate
•	Upon both validated the user can view everything except the Complete Address
